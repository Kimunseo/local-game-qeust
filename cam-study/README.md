# 아침 기상 캠스터디 앱

claude.ai 아티팩트였던 '아침 기상 캠스터디'를 휴대폰 홈 화면에 설치하는 앱(PWA)으로 옮긴 버전이에요.
출석 체크 · 기상 미션 · 벌금/예치금 · 말일 정산 규칙은 아티팩트와 똑같고, 데이터는 Firebase(무료 요금제)에 저장돼 회원끼리 실시간으로 공유돼요.

## 달라진 점

| | 아티팩트 | 앱 |
|---|---|---|
| 데이터 저장 | claude.ai 공유 DB | Firebase Firestore |
| 들어오는 방법 | '편집 가능'으로 초대 | **방 코드**가 담긴 초대 링크 |
| 설치 | 없음 | 홈 화면에 추가 → 앱처럼 전체 화면 실행 |
| 오프라인 | 안 됨 | 앱이 열리고, 끊긴 동안 체크한 것은 연결되면 자동 저장 |

기존 회원(똘님 · 데이지 · 압카)과 각자의 교시 · 기상 시간은 **회원 · 설정 → '기존 회원 불러오기'** 버튼 한 번으로 옮겨져요.
(아티팩트에는 아직 출석 기록이 없어서 옮길 기록은 이게 전부예요.)

## 처음 한 번만: 설치 가이드 (방장, 약 10분)

### 1. Firebase 프로젝트 만들기
1. <https://console.firebase.google.com> 에서 **프로젝트 추가** → 이름 예: `camstudy` (Google 애널리틱스는 꺼도 돼요).
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** 을 **사용 설정**.
3. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**.
4. Firestore의 **규칙** 탭에 이 폴더의 [`firestore.rules`](firestore.rules) 내용을 그대로 붙여넣고 **게시**.

### 2. 설정값 넣기
1. 프로젝트 설정(톱니바퀴) → **내 앱 → 웹(`</>`)** → 앱 등록 (호스팅 체크는 안 해도 돼요).
2. 보이는 `firebaseConfig` 값을 [`firebase-config.js`](firebase-config.js)의 `YOUR_...` 자리에 복사해서 저장.
   이 값은 공개돼도 괜찮은 식별자예요. 데이터는 규칙과 방 코드가 지켜요.

### 3. 인터넷에 올리기 (둘 중 하나)
- **GitHub Pages (추천, 무료)**: 이 저장소 → Settings → Pages → Branch를 이 코드가 있는 브랜치 / `root`로 선택 → 저장.
  몇 분 뒤 `https://<깃허브아이디>.github.io/local-game-qeust/cam-study/` 로 열려요.
  ⚠️ GitHub Pages는 저장소가 공개(public)여야 무료예요.
- **Firebase Hosting**: PC에서 `npm i -g firebase-tools` → `cd cam-study` → `firebase login` → `firebase use --add` (프로젝트 선택) → `firebase deploy`.
  규칙(`firestore.rules`)도 같이 배포돼요.

### 4. 방 만들고 초대하기
1. 앱 주소를 열고 **새 방 코드 만들기 → 입장**.
2. **회원 · 설정 → 기존 회원 불러오기** (또는 회원 추가).
3. **초대 링크 복사** → 카톡방에 공유. 회원은 링크를 열고 **내 이름 고르기**만 하면 끝.

## 휴대폰에 설치하기
- **아이폰(사파리)**: 초대 링크 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드(크롬)**: 초대 링크 열기 → 메뉴 ⋮ → **앱 설치** (또는 회원 · 설정의 '앱 설치' 버튼)

한 번 링크로 들어오면 방 코드가 기기에 저장돼서, 홈 화면 아이콘으로 열어도 같은 방으로 들어가요.

## 보안에 대해
- 방 코드를 아는 사람만 그 방의 데이터를 읽고 쓸 수 있어요. 방 코드는 비밀번호처럼 카톡방 안에서만 공유하세요.
- 아티팩트처럼 체크는 누구나 서로 대신 할 수 있고, 모든 체크에 누가 언제 했는지 남아요.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (출석 · 벌금 · 정산 · 설정) |
| `firebase-config.js` | Firebase 설정값 (직접 채우기) |
| `firestore.rules` | Firestore 보안 규칙 |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면 설치 · 오프라인용 |
| `firebase.json` | Firebase Hosting으로 배포할 때만 사용 |
